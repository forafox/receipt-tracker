## Обзор датасетов для распознавания чеков

Ниже перечислены датасеты, рассмотренные для проекта. Для дальнейшей работы выбраны ReceiptSense и cdek-ocr/receipt-ocr-ru.

| Датасет | Язык | Объем | Задачи и особенности | Доступ |
|---|---|---|---|---|
| SROIE | Английский | 1 000 изображений | Детекция текста, OCR, извлечение ключевой информации. Бенчмарк ICDAR 2019. | Kaggle, публичные зеркала |
| CORD | Индонезийский | 1 000 изображений | Post-OCR парсинг. 54 подкласса, 8 суперклассов. | Hugging Face |
| ReceiptSense | Арабский, английский | 20 000+ чеков, 30 000 OCR-изображений, 10 000 аннотаций позиций | Детекция, OCR, извлечение информации, QA. Подходит для LLM. | GitHub |
| AMuRD | Арабский, английский | 47 720+ позиций | Извлечение ключевой информации, классификация товаров по 37 419 категориям. | GitHub |
| KORIE | Корейский | 748 чеков | Устойчивость к дефектам термопечати: выцветание, полосы, складки. | Данные и код |
| Grocery Store Receipts | Английский | Около 20 изображений | Детекция текста. Bounding box для store, item, date_time, total. | Hugging Face, коммерческая лицензия |
| cdek-ocr/receipt-ocr-ru | Русский | Несколько сотен изображений | Детекция текста, OCR, извлечение полей. Bounding box и структурированные поля. | Hugging Face |
| MWS Vision Bench | Русский | 400 изображений, 1 302 задачи | Бенчмарк MLLM: парсинг, полностраничный OCR, KIE, VQA, text grounding. | Hugging Face, GitHub |
| NLP in Practice | Русский | Тысячи чековых позиций | NER, нормализация брендов и наименований товаров. | GitHub, ODS.ai |
| Receipt-AVQA-2023 | Английский | 1 957 изображений, 21 835 вопросов | Визуальный вопрос-ответ по чекам, числовой вывод. | Материалы соревнования |

### ReceiptSense
- Языки: арабский, английский.
- Объем: более 20 000 аннотированных чеков; 30 000 OCR-изображений; 10 000 аннотаций товарных позиций.
- Задачи: детекция текста, OCR, извлечение информации, QA.
- Особенность: QA-подмножество позволяет использовать датасет для оценки и дообучения LLM на изображениях чеков.
- Доступ: GitHub.

### cdek-ocr/receipt-ocr-ru
- Язык: русский.
- Объем: несколько сотен изображений чеков в форматах JPG и PNG.
- Разметка: bounding box для текстовых полей; структурированные поля: наименование товара, количество, цена, итоговая сумма, название магазина, дата.
- Задачи: детекция текста, OCR, извлечение ключевых полей.
- Назначение: дообучение и валидация русскоязычных моделей.
- Доступ: Hugging Face Datasets.

### Итог
ReceiptSense подходит для мультиязычных сценариев и задач с LLM/QA. cdek-ocr/receipt-ocr-ru подходит для дообучения и валидации на русском языке, а также для проверки извлечения полей на реальных чеках.
